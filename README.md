# ai-103

This repository contains the complete `Code for Students` workspace content copied into the `ai-103` repository.

## Included folders

- `00-Setup`
- `Foundry-Agent-Service`
- `Foundry-Models`
- `Foundry-Tools`
- `Translator` (legacy translator assets)

## Notes

- Local `.env` files and `.DS_Store` metadata are excluded from source control.
- Use the `Foundry-Tools` folders to explore individual Foundry tool deployments.
- Use the `Foundry-Agent-Service` folders for Browser Automation, Code Interpreter, and other agent demos.
- The repository is organized to preserve the original workspace structure.

## How to use

1. Open this repository in VS Code.
2. Review the notebooks under their respective folders.
3. Add your own values to `.env` files locally as needed.

- `00-Setup/setup.ipynb`

- `Foundry-Models/*`
